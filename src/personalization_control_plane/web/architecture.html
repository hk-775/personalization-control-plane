Implementation layers

Compact enough to inspect. Complete enough to exercise.

FastAPI provides the typed HTTP surface, a service layer owns all decisions and transitions, and SQLite retains a fully seeded local state.

01 / API

Typed ingress

Strict request models reject unknown fields and normalized values outside contract.

  • Health and portfolio
  • Policies and experiments
  • Ranking and events
  • Metrics and guardrails
02 / SERVICE

Canonical behavior

One application service owns governance checks, deterministic choices, lifecycle transitions, and rollback.

  • Purpose alignment
  • Risk classification
  • Stable allocation
  • Human approval gates
03 / STATE

Portable local evidence

SQLite stores policy versions, cohorts, experiments, approvals, decisions, events, metrics, and audit.

  • No external services
  • Idempotent event keys
  • Resettable demo seed
  • Hash-chain verification

AWS reference deployment

A proposed production path—not deployed infrastructure.

The reference view adds authenticated identity, multi-AZ serving, durable events, replicated state, independent audit evidence, and privacy-redacted operations while keeping consent and impact review explicit.

Deployment boundary

  • The local SQLite topology is not horizontally scalable.
  • Authentication and role enforcement are not included in the demo.
  • Candidate features are supplied, not learned or independently verified.
  • Fairness parity is a diagnostic, not proof of equitable impact.
  • Audit hashing detects mutation; it is not external notarization.
  • Production use requires domain-specific review and monitoring.
