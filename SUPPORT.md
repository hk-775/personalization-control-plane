# Support

This project is maintained on a best-effort basis without an availability or
response-time SLA.

- Use GitHub Discussions or issues for usage questions and reproducible bugs.
- Use private vulnerability reporting for security concerns; do not disclose
  vulnerabilities or credentials in a public issue.
- Include the project version, operating system, Python version, `uv` version,
  reproduction steps, and relevant sanitized logs.

The checked-in deployment is a local evaluation profile, not a supported
production service.
