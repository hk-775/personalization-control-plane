# Governance

Personalization Control Plane uses maintainer-led governance.

- Maintainers review changes for correctness, security, accessibility,
  responsible-use boundaries, and compatibility with the documented scope.
- Material security or ethical-risk changes require tests and an explicit
  discussion of failure modes.
- Decisions are recorded in pull requests and issues whenever disclosure is
  safe.
- Maintainer and ownership changes are reflected in `CODEOWNERS`.

The project may evolve this model as the contributor community grows.
